# Nights of Terror 0.1.3 playtest

November 25, 2026. Ran the packaged DLL in a visible foreground window on Super Fantasy Kingdom 0.8.068 with Hold the Line 0.2.3 and the combined Controller Test profile. The fixture used a copied Human day-13 save, normal game speed and a 1.5× interface.

The game supplied an original quota of 119 and showed 15 enemies still to spawn at dusk. The warning announced 60 reinforcements. All 60 spawned and remained alive simultaneously. Each matched the dusk pool and its native difficulty. The draw included 34 Shrooms, 13 Liches, eight Shamans, three Satyrs, one Efreet and one Djinn. [Dusk warning](screenshots/0.1.3/dusk-1.5x.png) · [Full midnight group](screenshots/0.1.3/full-midnight-group-1.5x.png)

The probe used controlled kills to verify completion. All 60 reinforcements emitted native death rewards. Hold the Line paid two coins once after combat cleared, and the tavern opened once. The private game exited with code 0. The ZIP also passed 592 managed checks. Natural combat balance with the larger group remains untested.
