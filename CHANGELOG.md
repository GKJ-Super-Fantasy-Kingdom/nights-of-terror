# Changelog

## 0.1.5

- Added `WavePercent` under `[Reinforcements]`. The default is 50% of the ordinary wave's original quota, rounded up. Set it between 0% (disabled) and 100%.
- Added an enemy icon and a highlighted reinforcement count to the dusk and midnight notifications.

## 0.1.4

Clarify the mod’s description and compatibility for players.

## 0.1.3

- Set the midnight group to half the original ordinary-wave quota, rounded up.

## 0.1.2

- Scaled midnight group size to the original ordinary-wave quota.
- Drew varied enemies and native difficulty levels from the pool selected by dusk.

## 0.1.1

- Increased the midnight reinforcement from three enemies to ten and updated the dusk warning.

## 0.1.0

- Added dusk warnings and a midnight reinforcement of three ordinary enemies.
- Kept combat, tavern entry and survival settlement open across both groups.
